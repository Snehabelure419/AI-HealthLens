# 🩺 AI-HealthLens — Multiple Disease Prediction Using Machine Learning

### An Intelligent Healthcare Prediction Web Application

AI-HealthLens is a machine learning-based healthcare application designed to predict the likelihood of multiple diseases using patient health data. Built with Python and Streamlit, the project provides a simple interface for interacting with trained machine learning models.

## ✨ Features

- 🫀 **Heart Disease Prediction**
- 🩸 **Diabetes Prediction**
- 🧠 **Parkinson's Disease Prediction**
- 🤖 Machine learning-based predictions
- 🖥️ Interactive Streamlit web interface
- 📊 Data preprocessing and model training
- 📓 Jupyter notebooks for experimentation and analysis

*The available prediction modules depend on the models and features implemented in the repository.*

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Jupyter Notebook

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Snehabelure419/AI-HealthLens.git
```

### 2. Navigate to the Project Directory

```bash
cd AI-HealthLens
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit Application

```bash
streamlit run app.py
```

The application should open in your browser at the local address provided by Streamlit.
